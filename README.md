# Gestão de Apoio à Habitação

Sistema web que organiza os programas de habitação em Portugal e ajuda o cidadão a decidir a quais se candidatar. Projeto 1 da UC **Aplicações Informáticas** (CTDI).

A aplicação reúne num só local os programas existentes (Porta 65 Jovem, Arrendamento Acessível, 1.º Direito, etc.), cruza-os com o perfil do cidadão para recomendar os apoios a que é elegível e permite acompanhar as candidaturas.

- **Utilizadores:** cidadão e administrador
